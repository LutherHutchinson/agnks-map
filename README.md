# 🌍 AGNKS Map — Навигатор по метановым заправкам

![Project Status](https://img.shields.io/badge/status-active-brightgreen)
![Tech](https://img.shields.io/badge/tech-JS%20|%20Yandex%20Maps-blue)

Современная интерактивная карта АГНКС (КПГ/СПГ) России и СНГ. Помогает водителям планировать маршруты на метане, учитывая график работы заправок, наличие удобств и отзывы других пользователей.

---

## ✨ Основные возможности

- 🗺️ **Интерактивная карта:** Самая актуальная база заправок Газпром и частных сетей.
- 🛣️ **Маршрутизатор с заездами:** Прокладывайте маршруты между городами и добавляйте промежуточные точки в один клик.
- 🕒 **Умные статусы:** Автоматическое определение "Открыто/Закрыто" с учетом часовых поясов и сложных графиков (перерывы, пересменки).
- 🔍 **Мощные фильтры:**
    - Фильтрация по расстоянию от маршрута.
    - Поиск по удобствам (WC, Кафе, Магазин, Оплата картой).
    - Выделение круглосуточных станций и станций "по пропускам".
- 💬 **Социальные функции:** Оставляйте отзывы, сообщайте об ошибках и добавляйте станции в "Избранное".
- 📱 **Mobile Ready:** Адаптивный интерфейс, удобный для использования в пути.

---

## 🛠️ Технологический стек

- **Frontend:** Vanilla JS, HTML5, CSS3.
- **Maps API:** [Yandex Maps JS API 2.1](https://yandex.ru/dev/maps/jsapi/).
- **Geometry:** [Turf.js](https://turfjs.org/) для расчетов расстояний и работы с геоданными.
- **Backend (Serverless):** [Supabase](https://supabase.com/) для хранения отзывов и избранного.
- **Tools:** Python-скрипты для автоматического обновления данных из API Газпрома.

## 🚀 Быстрый старт

### Локальный запуск
Для работы проекта нужен локальный сервер (из-за CORS и модулей):

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/LutherHutchinson/agnks-map.git
   cd agnks-map
   ```
2. Запустите сервер (Python должен быть установлен):
   ```bash
   python3 server.py
   ```
3. Откройте `http://localhost:8000` в браузере.

### Настройка API
Ключи API находятся в файле `config.js`. Для полноценной работы в своем домене рекомендуется создать `config.local.js` (игнорируется Git) и переопределить ключи там.

---

## 🔄 Обновление данных

В проекте есть скрипт для автоматического получения свежих данных от "Газпром Газомоторное топливо":

```bash
python3 update_stations.py
```
Скрипт обновит файл `gazprom_stations.json`, который автоматически подгрузится картой.

## 🏗️ Структура проекта

- `index.html` — Основная разметка и UI.
- `app.js` — Вся логика: работа с картами, фильтры, маршрутизация.
- `style.css` — Современный адаптивный дизайн.
- `stations.json` — База частных и партнерских АГНКС.
- `gazprom_stations.json` — Актуальная база АГНКС Газпром.
- `server.py` — Легковесный сервер для разработки.
