# 🌍 AGNKS Map — Навигатор по метановым заправкам

![Project Status](https://img.shields.io/badge/status-active-brightgreen)
![Tech Stack](https://img.shields.io/badge/tech-Docker%20|%20Python%20|%20PostgreSQL-blue)

Современная интерактивная карта АГНКС (метан: КПГ/СПГ) России и СНГ. Помогает водителям планировать маршруты на метане, учитывая график работы заправок, наличие удобств и отзывы других пользователей.

---

## ✨ Основные возможности

- 🗺️ **Интерактивная карта:** Актуальная база заправок Газпром (через API) и частных сетей.
- 🛣️ **Маршрутизатор с бюджетом:** Автоматический подбор заправок по пути с учетом запаса хода автомобиля.
- 🕒 **Живые статусы:** Определение "Открыто/Закрыто" в реальном времени.
- 💬 **Сообщество:** Регистрация, отзывы, сообщения об ошибках и "Избранное".
- 🛡️ **Админ-панель:** Удобный интерфейс для модерации данных и пользователей.

---

## 🛠️ Технологический стек

- **Backend:** Python (Dockerized), PostgreSQL.
- **Frontend:** Vanilla JS, HTML5, Vanilla CSS (Glassmorphism design).
- **Auth:** JWT для безопасной авторизации.
- **Maps API:** Yandex Maps JS API 2.1.

## 🚀 Деплой (Render.com) — Рекомендуемый способ

Проект полностью контейнеризирован (Docker), что гарантирует стабильную сборку всех зависимостей.

1. **База данных:** Создайте **PostgreSQL** на Render (тариф Free). Сохраните `Internal Database URL`.
2. **Веб-сервис:** Создайте **Web Service**, подключите GitHub. Render автоматически обнаружит `Dockerfile`.
3. **Переменные окружения (Advanced -> Environment Variables):**
   - `DATABASE_URL`: URL вашей базы данных (из шага 1).
   - `SECRET_KEY`: Любая длинная случайная строка.
   - `YANDEX_MAPS_API_KEY`: Ваш API ключ Яндекс Карт.
   - `YANDEX_SUGGEST_API_KEY`: Ваш API ключ Яндекс Подсказок.
   - `PORT`: 8080.

> **Примечание:** Вам не нужно создавать файл `config.js`. Сервер автоматически генерирует его на лету, используя переменные `YANDEX_MAPS_API_KEY` и `YANDEX_SUGGEST_API_KEY`.

## 🏗️ Локальный запуск (Разработка)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/LutherHutchinson/agnks-map.git
   cd agnks-map
   ```
2. **Запуск через Docker (Проще всего):**
   ```bash
   docker build -t agnks-map .
   docker run -p 8080:8080 -e DATABASE_URL=your_db_url -e SECRET_KEY=secret agnks-map
   ```
3. **Запуск без Docker:**
   - Установите PostgreSQL и выполните `schema.sql`.
   - `pip install -r requirements.txt`
   - `python3 server.py`

## 🛡️ Безопасность

Проект следует лучшим практикам безопасности:
- API-ключи никогда не попадают в репозиторий.
- Пароли в БД хранятся в виде защищенных хешей.
- Доступ к админ-панели ограничен на уровне JWT токенов.
