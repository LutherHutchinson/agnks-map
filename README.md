# 🌍 AGNKS Map — Навигатор по метановым заправкам

![Project Status](https://img.shields.io/badge/status-active-brightgreen)
![Tech Stack](https://img.shields.io/badge/tech-Python%20|%20PostgreSQL%20|%20JS-blue)

Современная интерактивная карта АГНКС (метан: КПГ/СПГ) России и СНГ. Помогает водителям планировать маршруты на метане, учитывая график работы заправок, наличие удобств и отзывы других пользователей.

---

## ✨ Основные возможности

- 🗺️ **Интерактивная карта:** Самая актуальная база заправок Газпром (через API) и частных сетей.
- 🛣️ **Умный маршрутизатор:** Прокладывает маршруты и автоматически предлагает заправки по пути, учитывая ваш запас хода (бюджет).
- 🕒 **Живые статусы:** Определение "Открыто/Закрыто" в реальном времени с учетом часовых поясов, пересменок и обедов.
- 💬 **Сообщество:** Регистрация, отзывы, сообщения об ошибках и система "Избранного".
- 🛡️ **Админ-панель:** Полноценный интерфейс для модерации отзывов, управления пользователями и обработки отчетов об ошибках.
- 📱 **Mobile Ready:** Полностью адаптивный интерфейс, оптимизированный для смартфонов.

---

## 🛠️ Технологический стек

- **Backend:** Python (HTTP Server), PostgreSQL.
- **Frontend:** Vanilla JS, HTML5, Vanilla CSS (Glassmorphism design).
- **Auth:** JWT (JSON Web Tokens) для безопасной авторизации.
- **Maps API:** [Yandex Maps JS API 2.1](https://yandex.ru/dev/maps/jsapi/).
- **Geometry:** [Turf.js](https://turfjs.org/) для гео-расчетов и анализа маршрутов.

## 🚀 Быстрый старт

### Локальный запуск (Разработка)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/LutherHutchinson/agnks-map.git
   cd agnks-map
   ```
2. **Настройте PostgreSQL:**
   Создайте базу данных (например, `agnks_db`) и выполните скрипт `schema.sql` для создания таблиц.
3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Запустите сервер:**
   ```bash
   python3 server.py
   ```
5. **Откройте браузер:** Перейдите на `http://localhost:8080`.

## ☁️ Деплой (Render.com)

Проект полностью оптимизирован для запуска на [Render](https://render.com/):

1. Создайте **PostgreSQL Database** на Render.
2. Создайте **Web Service**, подключив свой GitHub.
3. Укажите переменные окружения:
   - `DATABASE_URL`: URL вашей базы данных.
   - `SECRET_KEY`: Секретная строка для подписи токенов.
   - `PORT`: 8080.

## 🏗️ Структура проекта

- `server.py` — Основной бэкенд на Python (API, Auth, проксирование).
- `app.js` — Логика фронтенда, работа с картой и маршрутизацией.
- `index.html` — Главная страница приложения.
- `style.css` — Стилизация (Dark Mode, Glassmorphism).
- `schema.sql` — Схема базы данных PostgreSQL.
- `stations.json` — Локальная база частных АГНКС.
- `guide.md` — Текст инструкции по заправке.

---

## 🛡️ Безопасность

Проект использует переменные окружения для хранения чувствительных данных. Файл `config.js` занесен в `.gitignore` для предотвращения утечки API-ключей Yandex.
